# 林克时间

我的APP网站宣传页

## 本地预览方法

您可以直接双击 `index.html` 在浏览器中打开，或者使用任意静态 Web 服务器预览：

### 使用 npx serve
```bash
npx serve .
```

### 使用 Python
```bash
python -m http.server 8000
```

## 部署说明
本源码为纯静态 HTML 页面，包含 Tailwind CSS 支持，可以部署到任意静态服务器（如 Vercel, Netlify, GitHub Pages, Nginx 等）。
